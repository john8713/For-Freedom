# For Freedom

브라우저에서 dist/index.html을 열어 실행할 수 있는 10:16 카드게임 프로토타입입니다.

제공된 원본 이미지 11개를 사용합니다. 맵 10:10, 상태창 10:6, 기본 덱 8장, 패 5장, 체력 50, 코스트 5를 구현했습니다. 남은 패는 유지하고 턴 종료 시 5장까지 보충하며, 뽑을 덱이 비면 버림패를 섞습니다.

미지정 규칙은 테스트용으로 추가했습니다: 적 체력 20~25, 공격력 5, 거리 4칸 이내 추적, 상하좌우 인접 공격, 탐색 시 칸당 한 번 5% 확률로 기본 카드 6종 중 무작위 한 장 획득, 오른쪽 위 성문 도착 시 완료. 방어와 회피는 해당 적 턴까지만 유지됩니다. 다음 스테이지와 카드 보상 확장은 포함되지 않았습니다.

game.js의 cards와 start 함수에서 카드 및 적 구성을 변경할 수 있습니다. 업적은 브라우저에 저장됩니다.

1스테이지: 이름모를 초원. 이동 시 방향별 걷기 프레임과 0.56초 이동 애니메이션을 재생합니다. 스토리 GIF는 0.5배속(18초)입니다. 카드 발견은 맵 중앙에서 3초 동안 표시합니다. 패 카드는 마우스를 올리거나 터치로 0.18초 이상 누르고 있으면 2.5배 확대되며 길게 누르기는 카드를 사용하지 않습니다.
