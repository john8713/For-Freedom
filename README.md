# For Freedom — 이름모를 초원

`dist/index.html`을 브라우저에서 열어 실행합니다. 게임 화면 비율은 10:16이며 맵은 10:10, 상태창은 10:6입니다.

## 시작 규칙
- 체력 50, 기본 코스트 3. 턴 종료 시 코스트 회복.
- 기본 덱 9장: 타격 2, 이동 3, 발차기·방어·탐색·회피 각 1장.
- 패 5장. 남은 패 유지 후 5장까지 보충. 뽑을 덱이 비면 버림패를 섞음.
- 스토리 GIF 0.5배속, 총 18초. 주인공은 맵 왼쪽 아래에서 오른쪽을 보고 시작.
- 주인공과 토끼는 원본 스프라이트의 방향별 이동 프레임을 재생하며 이동. 토끼는 아래 방향 정지 상태로 생성.

## 획득 카드
| 카드 | 코스트 | 효과 |
|---|---:|---|
| 강한 타격 | 1 | 인접한 적에게 피해 7 |
| 기도 | 1 | 다음 턴 코스트 +1, 중첩 가능, 그 다음 턴에는 기본 3으로 복귀 |
| 반격 | 1 | 직전 적 턴에 실제 피해를 받았다면 인접한 적에게 피해 10 |
| 일섬 | 3 | 검 장착 필요, 인접한 적에게 피해 60 |
| 질주 | 1 | 상하좌우 최대 두 칸 이동, 빈 칸으로만 이동하며 방향 전환 가능 |
| 회복 | 1 | 체력 5~15 회복, 최대 체력 50 |
| 검격 | 1 | 검 장착 필요, 인접한 적에게 피해 15 |
| 셔플 | 1 | 나머지 패를 뽑을 덱에 넣어 섞고 넣은 수만큼 뽑음 |
| 트라우마 | 사용 불가 | 패에 남으며 별도 피해 효과는 없음 |

맵의 랜덤한 빈 칸에 검이 한 개 생성됩니다. 해당 칸에 도착하면 검을 줍고, 인벤토리의 무기 칸에 장착하면 검격·일섬을 사용할 수 있습니다. 조건을 만족하지 않는 반격·검 카드·트라우마는 카드나 코스트를 소모하지 않습니다.

## 보상과 탐색
- 토끼 처치 시 기본 카드를 포함한 전체 카드 15종 중 한 장을 무작위 제시. 획득하여 덱에 추가하거나 보상 건너뛰기 가능.
- 탐색은 칸당 한 번. 5% 확률로 전체 카드 15종 중 무작위 한 장을 덱에 추가하고 맵 중앙에서 '발견!'과 카드를 3초 표시.
- 패 카드에 마우스를 올리거나 터치로 0.18초 이상 누르면 2.5배 확대. 길게 누른 뒤 손을 떼어도 카드는 사용되지 않음.

토끼 체력 20~25, 공격력 5, 거리 4칸 이내 추적, 상하좌우 인접 공격은 기존 테스트 규칙을 유지합니다. 방어·회피는 해당 적 턴 동안 적용됩니다. 오른쪽 위 성문 도착 시 완료합니다.


## 자동 저장과 인벤토리
- 같은 브라우저에 진행 상황을 자동 저장합니다. 게임 시작 시 저장 데이터가 있으면 ‘게임을 이어하시겠습니까?’(예/아니오)를 표시합니다. 예는 복원, 아니오는 새 스토리부터 시작합니다. 완료·사망한 진행은 이어하기에서 제거됩니다.
- 덱, 패 순서, 체력, 코스트, 턴, 적, 탐색한 칸, 바닥 아이템, 인벤토리, 장비, 미선택 보상을 저장합니다. 이동·적 턴 도중에는 마지막 완료된 행동까지 복원합니다. 브라우저 저장 공간을 지우거나 다른 브라우저를 이용하면 저장은 공유되지 않습니다.
- 메뉴 왼쪽 인벤토리 버튼으로 맵 대신 인벤토리를 표시합니다. 버튼 위치에서 확대하여 열리고 같은 위치로 축소하여 닫힙니다.
- 아이템 보관 49칸, 무기·상의·바지·신발·모자·목걸이·반지(2칸) 장비 칸. 아이템은 드래그 또는 출발/목적지 칸 순서대로 클릭하여 이동·착용·해제합니다. 해당 종류의 장비 칸에만 착용할 수 있습니다. 현재 획득 가능한 아이템은 제공된 검입니다. 카드는 아이템 인벤토리에 들어가지 않습니다.
- 패 카드도 드래그하여 순서를 바꿀 수 있으며, 정렬에는 코스트가 소모되지 않습니다.
- 상태창의 방어 수치·검 장착 여부 문구는 제거했습니다. 방어 효과 자체는 유지합니다. 토끼는 공격 시 주인공을 바라봅니다.
